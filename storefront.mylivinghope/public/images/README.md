# Asset Directories

Drop assets into these folders and the components will pick them up:

## /images/cards/
3D card renders. Naming: `card-front-{emotion}.png`, `card-back-{emotion}.png`
Used in: Hero, ProductShowcase, decorative accents

## /images/product/
Product photography. Naming: `hero.jpg`, `lifestyle-1.jpg`, `detail-1.jpg`
Used in: ProductShowcase, About section

## /images/box/
3D box renders or poster frames. Naming: `box-poster.jpg`
Used in: BoxReveal component

## /video/
Box opening animation. Naming: `box-reveal.mp4` or `box-reveal.webm`
Used in: BoxReveal component (scroll-triggered autoplay)
